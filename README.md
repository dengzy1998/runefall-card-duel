RUNEFALL — A Deck-Building Card Duel: an original roguelite card battler. Build a 40-card deck across 3 acts, read the foe's telegraphed intent, chain same-element cards for Surge, draft new cards and relics between duels, face the Briar Queen and the Ashen King, and bank embers in the Sanctum to grow stronger across runs. Click cards or press 1–5 to play, Space ends your turn.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
